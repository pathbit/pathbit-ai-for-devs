# Fluxo reutilizável para planejar mudanças

Instale [a Skill](.claude/skills/planejar-mudanca/SKILL.md) no projeto conforme o [guia](../README.md). Leia o [mapa de rotas](.claude/skills/planejar-mudanca/references/aggregator-map.md) e o [modelo de proposta](.claude/skills/planejar-mudanca/templates/proposal.md) antes de usar o comando.

## Compare duas decisões de planejamento

Os [dois pedidos](prompts.md) usam o mesmo procedimento. No primeiro, defina se o contador mostra a página ou o total da busca. No segundo, confirme se os toasts já atendem ao pedido. Em ambos, a saída deve citar arquivos e trazer exemplos de aceite. Compare `git status --short` antes e depois.

Adapte o mapa para o seu sistema substituindo os caminhos e contratos do Agregador. Deixe as referências perto do procedimento e a proposta de cada mudança junto à sua especificação.
