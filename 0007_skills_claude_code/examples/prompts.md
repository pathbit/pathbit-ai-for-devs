# Exercícios no Agregador

## Mostrar quantos artigos aparecem no resultado

> /planejar-mudanca Mostrar no dashboard quantos artigos aparecem depois que a pessoa filtra por categoria. Diferencie a quantidade retornada do total armazenado.

A proposta deve citar `GET /artigos`, o filtro `categoria` e o código de renderização em `src/public/index.html`. Defina os casos de lista com itens e lista vazia. Para falar em total armazenado, identifique primeiro se a API devolve esse total.

## Exibir mensagens de favoritos

> /planejar-mudanca Mostrar no dashboard uma mensagem clara depois de favoritar um artigo ou remover um favorito.

Confira os pontos em que a aplicação já atualiza o estado e emite mensagens. Se houver comportamento existente suficiente, a proposta pode indicar que o pedido precisa de uma diferenciação para justificar outra mudança.
