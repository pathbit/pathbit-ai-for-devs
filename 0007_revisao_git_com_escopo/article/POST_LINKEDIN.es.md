# Publicación de LinkedIn sobre Revisión de Git con alcance verificable

[Português (Brasil)](POST_LINKEDIN.md) · [English](POST_LINKEDIN.en.md) · **Español**

Un cambio de un agente puede superar las pruebas y salir del alcance. El verificador del artículo 0007 lee cambios preparados, locales y nuevos. Un caso pasa en `src/app.py` y el segundo detecta un cambio protegido en `.github/workflows/check.yml`. La decisión sale en JSON. Ejecuta el laboratorio en una carpeta Git temporal.
